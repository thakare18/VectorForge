 *#VectorForge*

*A production-inspired Vector Database built from scratch in JavaScript to understand how modern vector databases like Pinecone, Weaviate, Chroma, and Milvus work internally*.

*VectorForge implements core vector search algorithms, similarity metrics, and a modular REST API without relying on external vector database libraries. The project is being developed incrementally to demonstrate the architecture behind semantic search and Retrieval-Augmented Generation (RAG) systems*.
